# 经营分析：数据与展示审计

核对对象：当前存储的经营分析导入快照（2026-09-22），19 张业务子表、1 张导入说明；后端 `crm_compute_dashboard_data`；前端单页看板。未修改导入快照。

## 发现的问题

1. **展示缺失**：后端生成 25 组业务数据，旧单页只展示其中部分。费用率、收入支撑、滚动冲刺、预算承接和已完成订单未形成分析入口；省份只展示 TOP8，子产业、区域任务令的收入/回款/毛利、订单质量等缺失。
2. **目标错配**：后端 `Q3订货任务令` 实际读取原表的“Q3管理订货任务令”。旧图将实际订货除以该目标，得到不对应的完成率。新展示使用管理订货，其他任务分别匹配收入、回款、含变更毛利。
3. **产业目标被遗漏**：原始“产业订货目标”已映射到 `P05_产业.订货目标`；上一版仍提示未设置。真实数据集成目标 50,000 万、实际 10,250.43 万、完成约20.5%。
4. **不同范围与目标混用**：核心订货11,785.82万，产业合计13,385.87万；核心表Q3订货目标33,000万，任务令联指管理订货目标22,000万；核心刚性费用Q3预算998.15万，任务令费用预算928万。分别展示来源与口径，不能用其中一个替代另一个。
5. **费用方向相反**：费用使用率并非越高越好，超支需显示超过100%；展示预算余额，而非将费用称为收入类目标达成。
6. **图形语义**：互斥的赢率分档并非转化漏斗；气泡图仅显示大于0的订货，隐藏零订货省份；气泡参考线套用公司毛利率目标，易被理解为各省考核目标。改为全量省份表和分档/阶段各自的明细。
7. **精度与空值**：费效比5.26不应只显示5.3；缺失实际不应变为0；达标订单量是数量，不是百分比。现按字段含义格式化，保留零值，缺失显示未提供。
8. **验证盲点**：旧利润桥测试数据使用“项目/数值”，真实契约为“科目/值/类型”，导致测试图里全为0仍通过；手机截图被导航覆盖。新的验证使用真实快照计算结果，检查所有来源表的行列及浅/深主题与手机布局。

## 新的阅读结构

### 图表优先交互（同日追加）

进一步调整为工作区式阅读：三维度切换 + 分析主题按钮 + 上一页/下一页，每次仅渲染一个主题。总览单独显示核心指标；图表主视图每次6组，放大视图每次8组，超出用图内分页，避免长页面和图内纵向滚动。点击默认打开加大字号的图表弹窗，使用“放大图表 / 数据表 / 原始数据”切换。统计范围说明收纳为可展开说明。新增 `scripts/verify_business_workspace.py` 验证主题、图内翻页、默认放大图、三视图切换和19张源表完整性。

主页面改为图表卡片网格，不直接展示表格：目标/实际对比条形图、费用环形图、历史折线图、利润/现金流正负条形图、质量/转化热力图。所有卡片支持点击或 Enter/空格打开对应的放大分析表；弹窗再展开相关原始子表，复合图关联全部来源。三层来源目录也通过弹窗提供完整19张表。项目清单图预览前8项并注明数量，放大表保留全量；聚合对比保留所有现有区域/产业。

验证补充：主页面实际DOM不存在数据表；逐个图表打开分析弹窗；默认折叠原始数据；来源目录逐表核对行列；真实快照确认五种图形均存在，并检查键盘交互与深浅主题。

公司整体 → 区域经营 → 产业经营。每层先展示关键比较与结果，深入分析默认可展开，完整来源表分层保留。金额比较显式注明万元/元；预测、储备、实际业绩分开。

## 边界

### 连续图表视图（2026-09-24 最新调整）

- 取消逐主题分页与图内翻页，公司、区域、产业按顺序在同一页连续展示，顶部按钮定位分区。宽屏三列，中屏两列，手机单列。
- 费用构成用环图；机会阶段按可参与份额绘制饼图，剔除合计行，超过六个阶段时显示金额前五项及其他阶段汇总，避免重复计算或漏算。负值不绘制饼图。
- 对比条形图、正负条形图、历史折线图与质量热力图继续保留。总览长图预览前五项并提示；点击还原放大图表，可切换完整数据表与原始来源。原有图表最多40项、项目图最多8项的预览上限仍保留，完整行列在数据表中查看。
- 不承诺所有图表挤进一屏；通过多列减少滚动，保留清晰字号与明确数值。

- 本次为展示层重构，没有重写后端导入与存量数据；部分后端统计年份/口径仍来自固定模板（2026年8月、Q3）。页面展示该模板口径，不能将导入时间视为统计截止时间。
- 后端聚合存在固定区域名、产业名与当前年份筛选；因此保留完整来源表，确保未进入固定聚合的行仍可查询。
- 源数据不同表之间的差额没有擅自“修平”；保留差异与来源，后续应由业务口径确认。
