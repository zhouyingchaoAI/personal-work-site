# CRM 极简优化收尾与验收

## 本批功能

1. 设置统一承接我方组织、区域地图、评分规则、权限和留痕；按原功能授权显示可编辑/只读入口，不扩大后端权限。客户和评估页移除重复维护入口。
2. 工作台为有管理能力的账号增加管理视图，分类显示授权范围内的逾期、14天久未跟进、负责人缺失及单点风险。风险线索不伪装成已创建协同任务；保留日常跟进视角。
3. 商机提供待关联筛选及最多五个可见名称候选，必须显式选择并保存。取消不写入；不存在可靠候选时人工选择。不会扫描改写正式历史数据；关联不可见也会提示核对，不擅自覆盖。
4. 商机待办改为一次遍历索引，避免对每个商机重复遍历全部待办。5000商机/20000待办合成测试耗时27ms，仅代表本机纯函数计算，不代表生产页面响应时间。

## 上线与数据边界

- 本轮不修改生产客户/商机记录、不更改任何正式授权，不新建真实账号，不批量迁移历史名称关联。
- 正式历史关联需要业务人员逐条确认；平台提供核对流程，不能把未确认的数据宣称已清洗完成。
- 尚不能宣称“全量验收通过”：除上述历史基线外，真实业务账号使用、生产全量性能和业务方确认未完成。功能交付与数据治理/正式验收分别记录。
- 本轮主要为前端更新，构建通过既有挂载提供，不需重启后端；未再次推送 Git。
