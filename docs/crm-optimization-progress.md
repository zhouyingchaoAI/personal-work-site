# 联指经营助手优化进度

## 2026-10-06：深度优化（性能 / 口径一致 / 代码与测试清理）

- 传输压缩：`backend/server.py` 的 `send_json` 与 `/assets/` 静态分支按 `Accept-Encoding` 返回 gzip（≥1 KB 才压缩，静态按文件 mtime+size 缓存压缩结果），`/assets/` 改为 `max-age=31536000, immutable`（Vite 文件名带内容哈希）。线上实测：主包 JS 1116 KB→355 KB，CRM CSS 248 KB→43 KB；管理员一次 CRM 全量加载 5 个接口 3567 KB→278 KB。此前 office 域名的 nginx 与应用均不压缩。新增 `tests/unit/test_http_compression.py`。
- 配置重复解析：管理员快照 `_crm_build_snapshot` 跨 165 个账号读取时 `read_config()` 被解析 170 次（≈0.5 s）。`backend/core.py` 新增 `config_read_scope()`，快照构建期内所有 `read_config()` 共享一次解析（只读约定，测试里对 `r.read_config` 的 patch 不受影响）。线上实测管理员未命中缓存的概览 1492 ms→476 ms。

- 联系人档案表：我方对接人改用后端解析的我方人员姓名（原直接显示账号/工号键），未指派显示“待指派”，并改为一次建索引不再逐行扫描全部关系；组织归属增加公司之下的分公司 / 单位 / 部门路径（相邻重复段去重）。
