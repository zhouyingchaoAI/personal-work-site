# CRM 专项权限与审计

能力：关闭、只读、编辑、编辑与导入四级；可设置授权截至日期（服务器本地时区，当日有效）。超级管理员拥有自身CRM全部能力和授权管理能力。未设置专项授权的旧账号继承助手入口权限，但默认只读。专项授权优先于旧助手开关。

数据边界：继续每账号物理隔离，不引入跨用户查询或超级管理员读取他人CRM的入口。所有CRM HTTP接口统一分类；未知写接口默认要求编辑权限，批量导入要求单独高级角色，作战地图生成视为分析只读。管理接口仅superadmin，撤销/到期下个请求生效。Skill入口调用同一授权检查。

管理页：当前用户的权限说明；超级管理员可搜索账号、设置角色和到期日，查看最近200条审计事件。审计事件包括读写/拒绝/授权变更，记录账号、接口、结果，不存请求正文和客户内容；应用无删除审计日志API。日志文件不等于具备外部不可篡改存储，服务器运维权限仍在本机制之外。

实现：backend/crm_security.py；权限文件和日志置于user_data/.crm-security，原助手权限查询接入专项角色。UI依据服务端能力禁用写入/导入控件；后端是最终校验。下载空模板不属于业务数据导出。当前没有客户数据导出API，不新增该通道。
