# 关系统筹简化

## 操作

- 关系指派：按客户组织（含下级）或多选客户联系人，选择目标我方人员，确认指派。保留原对接人，不额外创建监督任务。
- 关系转移：选择原人员和新人，默认添加共同对接；已有目标关系自动跳过。勾选移交替换时二次确认，更换原关系负责人，并按原接口移交原负责人未完成计划。历史互动不复制、不改写。
- 客户关系变化不自动授予系统管理权限。仅具有批量指派权限的用户显示新操作；后端逐项验证联系人可见范围与区域授权，校验失败前不写入。
- 单次上限500位联系人/关系。详细关系表和原有高级操作折叠保留。

## 验证

- 新接口先以未实现的person_ids请求观察拒绝，再实现并通过回归；界面先观察缺少新入口，再实现并验证。
- 生产构建通过（保留既有包体积警告）；16组前端测试通过。
- 本次新增指派、区域权限、重复提交、历史标识去重、人员目录权限和历史保护等测试与安全、跟进授权相关测试共27项通过。
- 隔离浏览器完成按组织指派、原关系保留、原人员到新人员重复添加、桌面及390px移动布局验证；不对正式客户数据执行指派或转移。
- 独立审查发现并修复人员目录依赖和历史标识去重问题；复核无新的重要问题。目标人员使用独立受批量指派权限保护的最小账号目录；原人员从可见关系提取，支持历史人员。
- 全量CRM测试223项，其中20个历史问题与此前基线失败名称一致；不声明全量通过。名称如下。
