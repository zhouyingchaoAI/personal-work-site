# 数据中台：助手与平台视角

数据中台以助手权限目录为准列出全部助手，另设“平台本身”，汇总账号、登录会话、用户资料、工单、智能体基础服务、模型网关、Dify 和 Foundry。数据中台助手本身仍管理同步、文件归档、连接注册及访问审计，不与平台身份配置混淆。

顶层管理对象选择对九个页签共同生效，通过 URL 的 `subject` 参数保留。对象切换后重建详情，防止上一个对象的表、预览或查询结果残留。未知的新助手保留入口并标记待核实，不推断其存储。

默认入口为“全局总览”，保留原全局资产分级、模块容量、用户排名、业务看板、全部数据库、完整助手及支撑系统拓扑和接口目录。助手目录在全局资产页默认折叠，不挤占原总览。助手与平台视角是附加筛选，随时可点“全局总览”返回；全局拓扑点击节点仅局部高亮，不自动切走全局界面。

| 页面 | 对象视角 |
| --- | --- |
| 数据资产总览 | 每个助手及平台的数据种类、主存储形式、关联实例，跳转携带对象 |
| 存储对应 | 当前对象具体数据、实际读写位置与镜像证据；平台支撑系统合并到平台本身 |
| 数据看板 | 按对象归属显示已提供的业务指标；无指标明确提示，不显示虚假零值 |
| 原始数据 | 服务端按登记路径过滤，先过滤再分页；只显示有相关文件的用户目录 |
| 数据接口 | 按对象显示已登记数据集；员工目录为共享数据，平台与 CRM 都可引用 |
| 数据库 | 当前对象关联实例及相关表；自由 SQL 仅在全局视角展示 |
| 数据流向 | 全局保留独立支撑系统节点与局部高亮；专项视角显示所选助手或平台的关联实例及告警 |
| 备份与恢复 | 显示平台统一备份保障，不伪造单助手备份记录 |
| 存储与服务 | 筛选相关服务和镜像表；主机磁盘、归档规模、同步结果与迁移计划明确为平台级 |

## 统计边界

资产总览与存储对应均提供“助手入库进度”，按已登记的实际主存储归为：全部数据库、数据库 / 对象存储、数据库与文件混合、本地文件、外部 / 待核验。每类直接列出助手名称，平台单独统计。只要存在本地文件或未核验数据，就不会标成全部数据库；已成功的镜像和归档不改变主存储分类。SQLite 属于数据库，但不代表已迁入统一 PostgreSQL。点击助手可进入具体数据清单。

- 模块扫描是本地文件容量，不包含外部数据库体积。CRM 旧文件属于切换前快照，不能作为当前业务数量来源。
- CRM 看板及 live 取数读取当前主存储；结构化查询标注业务主库，不再将历史同步时间误标为数据新鲜度。
- 共享报告目录、SQLite 表、原始文档镜像及文件索引可能服务多个助手，相关性不代表独占归属。不累加为单助手规模。
- 实例连接数、吞吐、告警为整库口径；选中助手只是筛选关联关系，不意味着能将整库流量归因到该助手。
- 没有登记路径、业务指标、接口或监测实例，不等于没有数据；外部 / 未核验项保留说明。
- 管理对象筛选不是授权隔离。所有接口仍要求超级管理员；平台 API 密钥作用域不因页面筛选改变；脱敏、只读及审计约束不变。
- 备份与同步按钮始终执行全平台操作。数据库健康检查成功不证明其数据已纳入平台备份。

## 2026-09-30 界面精简（v2）

- 头部只保留两个控件：**对象下拉框**（全局总览 / 助手分组 / 平台本身，可搜索，选中写入路由 `?subject=`）和一个 **「操作」菜单**（重新扫描数据资产、立即同步入库、备份整个平台、刷新助手目录）。原“管理对象”卡片的 19 个按钮与散落各处的操作按钮全部收拢。
- 头部下方是 4 个 KPI：本地文件资产、助手切库进度（按业务主存储判断）、数据服务在线、备份·入库同步。
- 页签由 9 个大卡片改为 7 个细页签：总览 / 存储对应 / 数据看板 / 原始数据 / 数据接口 / 数据库（内含“实例浏览 | 实时流向”切换）/ 运维保障（原“备份与恢复”+“存储与服务”，口径说明折叠）。
- 总览页的“助手入库进度”改为按状态分行、助手名称芯片（芯片上的小圆点数字＝数据库 / 文件 / 对象 / 待核验 的数据类数），点击进入该助手的存储对应；专项视角下顶部出现蓝色“当前视角”条，一键返回全局。
- 验收脚本：`scripts/verify_datacenter_ui_v2.py <截图目录>`（替代旧的 verify_datacenter_subject_ui / storage_ui）。
- 助手 ↔ 数据库关联图（`RelationGraph.vue`，上排助手/支撑系统、下排数据库实例，共用 `flowScope.ts` 裁剪快照）：总览页与“数据库 › 实时流向”共用同一组件。点助手高亮其连线与库并在下方列出关联库（业务存储 / 定时镜像 / 不可达），再点高亮的库出相关数据表（`/flow/tables`）；点库反查在用的助手。节点显示去括号短名，完整名在悬停提示。DOM 钩子：`[data-testid=dc-graph]`、`[data-graph-assistant=<id>]`、`[data-graph-instance=<id>]`、`[data-testid=rg-panel]`。
