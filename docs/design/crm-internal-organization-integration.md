# 我方部门岗位人员的业务联动

2026-09-08

固定 member_key 作为现有关系、项目节点和待办负责人引用，staff.id 用于我方汇报层级。展示姓名、部门和岗位时从当前账号人员档案解析；旧文字负责人不根据同名推断，不改变数据权限。

- Excel经营收集表和页面收集增加我方姓名、公司、部门、岗位四个选填字段，创建/补全空字段；冲突报错且在客户写入前校验；旧15列表格仍兼容。
- 档案、关系、待办、图谱、驾驶舱共享部门/人员筛选；关系按对接人、待办按负责人筛选。
- 联系人档案、关系、动作负责人选择、图谱连线说明、详情、作战建议显示人员部门岗位。
- 驾驶舱支持五方客户布局与我方部门责任切换；区域对比明确为全部部门，部门客户数按当前范围计算。
- 项目节点可选择我方人员，作战候选按我方范围限制；覆盖热力图保留项目全貌。岗位不作为未经验证的评分加权，也不等于系统授权。
- Staff更新失效总览缓存，旧缓存缺少staff_schema时重建。
