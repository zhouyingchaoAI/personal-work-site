# 联指经营助手全页面审查与统一优化

依据本次隔离环境截图：9个页签，收集/单位/联系人/关系/动作/项目节点弹窗，项目覆盖，超级管理员/客户经营管理员/只读空状态。使用虚构业务数据，未访问真实客户资料。

已确认问题：
1. 通用头部、Excel工具及统计卡重复占用每页首屏，帮助/权限页面也显示业务统计。
2. 客户档案两张宽表并列造成页面横向溢出，联系人未突出收集表的重要程度、支持程度与周期。
3. 区域仅在驾驶舱及档案生效，跳转关系/组织/待办后范围丢失。
4. 关系列表缺少搜索、我方对接人与历史详情；部分只读按钮仍允许点击后才报拒绝。
5. 项目热力图仅用颜色区分覆盖，表单控件缺少持久标签。
6. 组织树全部展开、帮助全文展开、长表单滚动不统一；日志使用英文动作标识。
7. 数据刷新并发读取可能造成总览与关系评分不一致；动作表单默认勾选有效动作，不利于事实确认。

统一设计：保留科技蓝驾驶舱，操作页面使用浅色表格与蓝色主按钮。导航按驾驶舱→档案→组织→关系动作→关系总览→作战地图→业务指南→使用说明→安全权限排序。顶部只保留角色、刷新、帮助、Excel收集、信息收集入口；地域作用于客户页签，项目覆盖明确按项目全貌计算。档案改为全宽联系人/单位切换；补充搜索、详情、中文字段和分页。所有写按钮使用已有权限控制，保留只读详情。辅助信息折叠，弹窗使用统一可滚动正文与固定操作区。

验证：区域跨页回归脚本先复现错误；完成后验证9页与主要弹窗，1600/390宽度，有数据及只读空状态，导入/详情/区域/分页/项目/待办/权限控制。截图只能发现视觉风险，不等同于完整无障碍认证。
