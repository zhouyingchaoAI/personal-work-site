# 我方组织画布

入口：设置 → 用户管理，以及联指经营助手 → 组织架构 → 我方组织。两处共用 `InternalOrganizationEntry` / `InternalOrganizationCanvas`，仅超级管理员可读取、保存正式账号组织结构。

## 数据与操作

- 初次打开只读账号公司、部门路径，生成公司和任意多级部门节点，不写配置。
- 结构保存在 config 的 `internal_organization.nodes`；人员归属以 `users[].company / department` 为准。空部门可以保留；人员账号、工号、岗位、密码、角色、授权字段均不修改。
- 新增下级、改名、修改上级、人员拖放或归属选择先进入草稿，点击“保存组织调整”统一保存。关闭弹框保留当前页面草稿；离开页面不保留未保存草稿。
- 节点自由位置仅保存在当前用户浏览器，不代表组织上下级。层级通过“修改上级”调整；自动排版、缩放、折叠、子节点详情沿用客户组织画布。
- 已通过画布迁移的正式人员，CRM 全局目录和个人覆盖档案的公司/部门在读取时按账号信息解析；不复制或变更 staff ID / member_key，不修改客户关系、联系人、行动记录。
- 部门/公司变更会影响基于组织归属计算的既有数据可见范围；不会新增授权。
- 乐观版本校验覆盖账号组织资料及结构；旧草稿不能覆盖其他入口或 Excel 同步后的新资料。拒绝循环、失联父节点、同级重名、遗漏人员、无效目标。
- 最多 3000 个节点，公司名称 200 字，完整部门路径 500 字；没有三级限制。

## 验证

`python3 -m unittest tests.unit.test_internal_organization`

`python3 tests/internal_organization_browser.py`

浏览器测试使用临时配置和临时 CRM 数据；验证两处入口、部门分支移动、跨公司拖放、保留身份与客户记录、非超级管理员接口拒绝。截图目录可用 `CRM_ARTIFACT_DIR` 指定。
