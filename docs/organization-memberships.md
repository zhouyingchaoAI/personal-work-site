# 组织人员兼任与快速添加

适用入口：用户管理的“调整我方组织架构”，以及五位一体的“客户组织架构 → 调整架构画布”。

## 操作

1. 点击组织节点，或通过顶部索引定位组织。
2. 点击“添加已有人员”，按姓名、工号/账号、职位或组织搜索已有档案。
3. 点击“添加人员”，同一人员保留原主归属，并在目标组织作为兼任显示。不创建重复账号或联系人。
4. 已兼任人员显示“移除兼任”；移除只解除当前兼任，不删除档案、主归属、关系或行动记录。主归属不可通过此按钮移除。
5. 我方组织修改先进入草稿，需点击“保存组织调整”；客户组织兼任操作即时保存。重开页面后仍保留。

## 数据与权限

- 客户联系人沿用 `unit_id` 表示主归属，`unit_ids` 表示额外兼任组织；我方账号主归属仍由公司、部门决定，额外关系保存在配置的 `internal_organization.memberships`。
- 老数据无需迁移；未提供兼任字段的保存请求保留既有兼任。
- 我方兼任只影响组织展示，不扩大公司/部门授权，不改变角色、工号、岗位、密码。主归属调整仍遵循原有授权规则。
- 客户快速索引只读取当前可见人员；保存继续执行原有档案归属与版本校验。兼任不会自动将档案授权给另一区域或账号；不可编辑的他人档案仍拒绝保存。
- 客户组织树、画布和组织汇总展示兼任；汇总沿祖先链按人员去重。其他销售指标、责任人、汇报关系仍沿用主归属，不随兼任自动转移。
- 同一人最多100个兼任组织，重复目标自动去重；有直属或兼任人员的组织不可直接删除。
- 兼任组织暂不单独设置岗位和汇报上级，沿用人员档案中的信息。拖动原有人员仍表示调整主归属，不等同于添加兼任。
