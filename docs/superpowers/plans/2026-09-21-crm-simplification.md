# CRM 极简操作实施计划

**目标：** 按用户确认的评估推进，让首页显示优先任务，商机建议可落成计划，减少重复填写和导航。
**架构：** 复用既有授权快照、动作及待办接口；新增工作台组件，保留地图入口。商机增加可选组织 ID、销售阶段及成交结果，兼容原项目阶段和旧导入记录。
**技术：** Vue 3、Element Plus、Python。
**依据：** 用户于 2026-09-21 粘贴确认的 CRM 极简评估。

## 约束及复核

- 不改生产业务数据，不改变权限边界；本地凭据差异不纳入本次修改。
- 计划不算真实互动；建议创建前确认已有关系、负责人及日期。
- 保存失败保留草稿，保存中禁止重复提交。
- 旧商机名称关联只作兼容；明确 ID 不回退匹配其他客户。
- 工作台使用授权数据，标明范围；日期按本地日历日显示，缺日期单列。

## 实施顺序

- [x] 工作台：新增 Workbench.vue，优先显示最多八项逾期/今日/未定日期任务，复用查看及完成操作；地图按需进入。
- [x] 商机：OpportunityManagement.vue 使用异步保存回调；新建入口、明确客户选择、销售阶段与结果、分页；后端保留及验证新字段，记录结果变更时间。
- [x] 跟进：精简常用字段，其他信息折叠；作战建议创建 record_kind=plan 的记录，沿用 crmAddAction 和原权限。
- [x] 导航：四个主入口；推进建议收纳到商机，设置入口承接权限；缩短 Hero 与卡片说明。
- [x] 验证：后端新字段/隔离/计划回归、前端构建、隔离浏览器模拟保存失败、新建、创建计划、导航和手机布局。

本批优先交付连续可用的主流程。客户详情深度重组、正式销售阶段门槛、停滞阈值及收入预测需要独立业务口径，保持为后续事项。

## 验证与边界

- 15 项后端专项通过，覆盖客户关联、非法/不可见关联、非目标客户联系人拒绝、旧数据兼容、版本冲突、结果变更、导入保留新增字段、导出和计划评分隔离，以及原动作/完成权限。
- 11 组前端纯函数回归通过；生产类型检查及构建通过，保留现有日记样式 :deep 与包体积警告。
- 隔离浏览器使用临时账号和虚构业务数据，验证默认工作台、四个主入口、保存失败保留草稿及重试、新建商机、建议转计划、完成任务、记录真实沟通、768/390px 布局。移动截图先关闭响应式导航抽屉。
- 扩展 Excel 回归的 test_missing_our_member_stays_blank_instead_of_account 报 IndexError；用 HEAD 中 crm.py/crm_excel.py 在内存替换后单独执行同样失败，确认并非本轮引入。未宣称全量测试通过。
- 无业务数据迁移，未执行线上服务重启；后端新字段及校验需运行更新后的 Python 服务。未再次推送 Git。
- 旧商机无明确客户 ID 时仍保留原名称匹配兼容路径；本批未批量确认历史关联。新增销售阶段为统一基础选项，未实现阶段审批门槛、丢单原因分析或收入预测。
- 区域配置入口归入“更多”；评分规则和我方组织仍在原业务视图，后续再统一收纳。

## 第二批：客户工作区与久未跟进提醒

继续沿用用户已确认的极简评估。本批以只读派生数据整合为主，不新增权限或生产数据迁移。

- 新增 customerWorkspace.ts：按授权组织层级汇总联系人、关系和明确 ID 关联商机，处理缺失父节点和循环；名称相似不构成客户关联。
- 新增 CustomerWorkspace.vue：客户总览默认入口，详情只有概况、联系人、动态；串联查看商机、带入客户新建商机、联系人档案与记录跟进。互动和计划分别展示。
- Workbench.vue 增加久未跟进提醒：默认14天，可切换30/60天；按关联商机的真实互动日期判断，无互动时从建档日计算。未来日期、计划和其他物理归属账号的同编号动作不刷新日期；缺日期不判断停滞；赢单、输单和取消排除。阈值只影响当前查看，不持久化成经营制度。
- 更新 UsageGuide.vue 说明新入口及实际权限范围。
- 验证：新增纯函数测试覆盖组织层级、范围隔离、日期边界、缺值、未来/计划排除和账号隔离；扩展临时数据浏览器流程验证客户详情、预填新建、商机跳转、历史刷新及手机抽屉。

本批的“久未跟进”是登记互动提醒，不等同于商机实际没有进展；当前未按阶段变更推断经营成果。其他账号记录的同编号项目因无全局商机 ID，保守地不合并到停滞依据。

第二批验证结果：前端12组测试及后端15项相关专项通过；生产类型检查和构建通过。隔离浏览器覆盖上述客户流程及第一批写入链路，768/390px布局检查通过，无页面错误。测试按真实交互顺序在打开客户抽屉前切换视口并关闭应用导航，避免点被模态抽屉遮挡的底层按钮。未改生产客户数据，未再次推送或重启线上后端。

只读代码复核无确认的严重或重要问题。已补齐14/30/60天边界和真实互动解除提醒的纯函数断言。保留轻微改进项：查看商机目前通过编号关键词筛选列表，编号前缀相同或跨账号同编号时可能显示多条，并非按唯一记录自动打开详情；后续统一商机全局身份时再收敛。
